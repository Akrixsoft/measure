# Легенда трасс

`index.html` — автономное интерактивное превью: таблица 10 типов, цветной и чёрно-белый образцы, изменение примера выбором типа. Не загружает ресурсы из сети и не меняет приложение.

`legend.svg` — самостоятельная векторная таблица; `board.png` — обзорный снимок браузерного превью. Рисунки линий и коды соответствуют `MeasureLabRouteCatalog`, включая электрическую трассу с длинным пунктиром. Это условная легенда приложения, не заявление о соответствии ГОСТ.

Типы: el, lo, wa, wh, dr, ht, ufh, ga, ve, ot. Каталог экспортирует `get(id)`, `pattern(id, dpi)` и `style(route, dpi)`. `dash: true/1` включает рисунок типа; `false/0` — сплошную линию; отсутствие флага сохраняет прежний пунктир `[10,4]`. Короткая подпись позволяет отличать типы без цвета.
