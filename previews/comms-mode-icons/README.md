# Варианты значка режима коммуникаций

Откройте `index.html`: полностью автономный интерактивный файл, без сети и внешних ресурсов. Нажатие карточки обновляет только образец верхней панели.

1. `option-1.svg` — розетка + размеры.
2. `option-2.svg` — точка + два направления (рекомендация: универсальный знак коммуникации и замера).
3. `option-3.svg` — связи + размер.
4. `option-4.svg` — стена + точка замера.
5. `option-5.svg` — коммуникации + линейка.

Все SVG имеют `viewBox="0 0 32 32"`, используют `currentColor`, без растров и внешних зависимостей. В HTML показаны 76 px и реальные 32 / 24 CSS px, тёмный обычный и жёлтый активный варианты. Исходный SVG можно вставить непосредственно в кнопку приложения после выбора пользователя. Текущая кнопка приложения не изменялась.

Для обзорного PNG: ширина окна 1200 px, высота 740 px; вся область `main` содержит пять карточек и образец панели.
