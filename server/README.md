# Сервер Measure — распознавание фото стены (Google Apps Script)

Ключ AI хранится только на сервере (свойства скрипта), на телефоны не попадает. Без сервера или без сети Measure работает в полуавтомате.

## Установка (один раз, ~5 минут, с компьютера)
1. https://script.google.com → **Новый проект** → назвать «Measure сервер».
2. Вставить целиком `server/Code.gs` вместо текста в редакторе → 💾.
3. ⚙ **Настройки проекта → Свойства скрипта → Добавить**:
   - `ANTHROPIC_API_KEY` — ключ API;
   - `TOKEN` — любой длинный пароль (например, 20 букв и цифр);
   - `MODEL` — не нужно (по умолчанию `claude-opus-5-5`).
4. В редакторе выбрать функцию `test` → ▶ (разрешить доступ) → в журнале: «ключ: есть · токен: есть».
5. **Развернуть → Новое развёртывание → Тип: Веб-приложение** → «Выполнять как: я», «Доступ: все» → **Развернуть** → скопировать адрес `…/exec`.
6. В Measure: ⋮ → ⚙ Настройки → **AI-сервер Measure** — адрес `…/exec`, **AI-токен** — `TOKEN` из шага 3.

## Как работает
- Measure (🔍 у фото) шлёт фото (сжатое, ≤ 1600 px) и список видов; сервер спрашивает AI и возвращает углы стены и найденное (рамки, 0…1000).
- Ответ AI — строгий JSON по схеме; при отказе модели — резервная модель (`fallbacks: "default"`).
- Ошибка, нет сети, нет ответа за 90 с → Measure пишет «AI недоступен — полуавтомат».
- После правки Code.gs: **Развернуть → Управление развёртываниями → ✎ → Версия: новая** (адрес не меняется).
