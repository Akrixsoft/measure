# Проверка Measure Lab 0.12

## Новые сценарии

Все три сценария пройдены в мобильном Chromium Headless Shell с эмуляцией экрана 412×915, DPR 2. Для размещения и выбора в основных сценариях использованы события CDP с типом указателя pen. Распознанный контур для теста правки подготовлен фикстурой. Отдельный тест подложки загружает PNG через штатный путь распознавания.

| Команда | Проверки |
| --- | --- |
| `node tests/qa-v012-plan.cjs` | Три зоны с виртуальными границами и открытой полилинией стен, отказ при перекрытии, переименование и замена контура, два назначения стен, сохранение и JSON. Сдвиг, разбиение и удаление через кнопки плана. Постановка колонны пером у стены и прямого угла, проверка геометрии у наклонной стены, а также притяжения узла к маркеру другой стены. |
| `node tests/qa-v012-underlay.cjs` | PNG с ломаным внешним контуром, штатная первичная заливка, разделение исходной области, три заливки через виртуальные границы. Повторное касание выбирает существующую область. Число физических стен сохраняется. |
| `node tests/qa-v012-wall.cjs` | Зона и электрощит созданы протяжкой. Ввод ширины, высоты, Z и отступов. Правый отступ сохраняется при изменении ширины зоны и размера стены. «Провод» создаёт точку. JSON возвращает все три типа и глубины. |

## Регрессия

- Основная браузерная проверка экспериментальной версии — 14/14. Сценарии 0.11 — 54/54 для трасс стены, 22/22 для трасс и размеров пола, 38/38 для отображения углов, 8/8 для потолочных трасс. В том числе проверено сохранение старой многоточечной полилинии.
- Дополнительно прошли Aa 65/65, стрелки 0.5 101/101, браузерная подложка фото 5/5, проверка соседней стены, проверка интерфейса и размещение выбранного объекта.
- `export-consumer.cjs` прошёл на выгрузках открытой комнаты, отдельной плоскости и расширенной комнаты. `export-floor-consumer.cjs` прошёл на метаданных пола.
- Восемь старых сценариев завершились с ошибками и на архивной 0.11 — стрелки 0.2, последовательное размещение 0.3, привязки и жизненный цикл 0.4, пол 0.6, ряд коммуникаций 0.7 и 0.8, зона 0.9. Сценарий 0.9 дополнительно ожидает старые 13 инструментов и прежний ключ точки щита. В 0.12 ряд содержит 14 инструментов, прежняя позиция точки переходит «Проводу», электрощит добавлен отдельно. Новая проверка зоны и щита прошла.

## Ограничения

Проверки проводились в браузере и средствами Android SDK. Установка и работа на физическом Android, BLE-дальномер, аппаратное перо, съёмка камерой и системные диалоги выбора и выгрузки файлов требуют проверки на устройстве. Код мостов сохранён. Проверка конструктора относится к существующему контракту, а новые поля областей и щита проверены в обмене между экземплярами Measure Lab.

Исходный архив 0.11 содержал исходники без каталога Git. Коммит d099992 по истории подтвердить нельзя. Изменения закоммичены поверх отдельного локального коммита импорта этого снимка. Контрольная сумма исходной v81 совпала с константой скрипта сборки.

## APK

Сборка `python3 scripts/build_apk.py` прошла на Gradle 8.7, JDK 17, SDK 34 и Build Tools 34.0.0. `apksigner verify --verbose` подтвердил подпись v2, `zipalign -c` и проверка SHA-256 прошли. Проверено точное совпадение всех 26 ассетов в APK с исходниками, включая исходную v81. Манифест подтверждает пакет `ge.akrix.measure.lab12`, версию 0.12, код 12, имя «Measure Lab 0.12» и отдельный URI-авторитет для файлов.
