# Measure 82.14 — режим «Скетч»

Пакет `ge.akrix.measure`, версия 82.14, код 82014, ключ v81 — обновление поверх 82.13. Исходная v81 не изменена (SHA-256 сверяется сборкой). Задача AKX-2026-0007, основа — подтверждённый прототип v7 (`prototypes/sketch/sketch.src.html`).

## Вход
- Список замеров: кнопка «✎ Скетч» рядом с «＋ Помещение» (объект — из поля «Объект»).
- Меню «Ещё» (⋮): «✎ Скетч объекта» — объект открытого помещения / стены.
- Без объекта — окно выбора объекта (список известных объектов).

## Холст объекта
- Один холст на объект: фото 📷 камера / 🖼 галерея (несколько), заметки «Т» — на фото, на чертеже или на свободном месте холста.
- Сохранение — автоматически, в своей базе IndexedDB `akrix-sketch` (холст и фото). База замеров `akrix-zamer` не меняется, пока не нажата «Создать стену».
- ⇪ — файл JSON со всеми фото (перенос на другой телефон), ⇩ — загрузить такой файл в текущий холст.

## Фото → чертёж стены
- ⌗ Углы: 4 угла стены по потолку и полу (ЛВ, ПВ, ПН, ЛН), готовый угол тянется пером, мышью или пальцем.
- ↔ Размер — на фото или на чертеже (на чертеже строго гор./верт.). Ввод — штатное поле и клавиатура v81, лазер — туда же.
- Размер от края до края задаёт длину L / высоту H точно; без размеров стена условная (≈, по пропорции фото).
- Остальные размеры привязываются к ближайшему краю (стена, излом вида сверху, колонна, объект); привязка запоминается — объект двигают, размер идёт с ним.
- ▭ Объект: ригель, короб, колонна, ниша, проём. Поле Z: выступ +, ниша − (знак по виду).
- Объект, поставленный или подвинутый руками на чертеже, размеры не двигают, только проверяют: расхождение — красное «≠».
- ◉ Точка: все точечные коммуникации v81. Розетка и выключатель — посты 1–5, точка — центр первого подрозетника, остальные вправо с шагом 71.
- Вертикальная подпись размера — снизу вверх, по центру стрелки.

## Вид сверху
- ⌐ Ломаная: изломы касаниями, притяжка к прямой (≤ 12°) и к точкам; длина участка — касанием числа (следующие участки сдвигаются).
- ▯ Колонна: протяжкой; с магнитом грань ложится на стену, край — к концу/излому стены (подсветка). Поля ширины, глубины, отступа от края стены.
- Изломы и колонны видны на чертеже стены полосами с Z и служат краями привязки.

## «Создать стену» (панель стены)
Выбор помещения из списка или «＋ Новое помещение» (объект, имя); стена — существующая или «＋ Новая стена плана» (продолжение открытой ломаной, поворот 90°).
- План: стена с длиной L (замер — в размеры плана; «≈» — только геометрия), H помещения — если не было.
- Вид стены: чистая стена L × H; фото — на стене (выпрямлено по 4 углам, 👁 и «рядом» — штатно).
- Объекты → элементы стены (ригель, короб, колонна, ниша, проём) с D → объёмы w3Vols (D + наружу, − ниша; ∠° и раскрытие боковых 0–180° — как в 82.13).
- Участки ломаной со смещением → «колонна» во всю высоту с D = смещение (выступ стены), колонны вида сверху → «колонна» во всю высоту (D — от линии стены).
- Точки → коммуникации (розетки/выключатели с постами, шаг 71), размеры → ручные стрелки с введённым значением, заметки → выноски.
- У стены уже есть вид — «Заменить вид стены» (повторное нажатие); прежний вид помечается удалённым.
- После создания открывается вид стены; скетч помнит связь (✓ стена создана, «⟳ Стена снова»).
