# Measure Lab 0.4 — привязки постов и расстановка без дубликатов

## Новый порядок расстановки

Для коммуникаций и остальных элементов стены:

1. Первое касание или протяжка создаёт один объект; объект остаётся выделенным.
2. Пока он выделен, стилус перемещает его. Новый объект этим жестом не создаётся.
3. Касание в стороне только снимает выделение.
4. Следующее касание или протяжка создаёт следующий объект тем же инструментом.

Касание существующего объекта при отсутствии выделения выбирает его вместо создания копии. Смена инструмента очищает прежнее выделение. Прерванное перемещение при отмене указателя, начале масштабирования двумя пальцами либо смене инструмента откатывается; случайная точка не добавляется. Используются исходные механизмы жестов, перемещения, сохранения и отмены v81. При включённом режиме стилуса касания пальцами сохраняют штатную роль перемещения/масштабирования вида.

Автоматические стрелки элементов не возвращаются. Ручные размеры, подписи, выбор стороны отсчёта и ввод через родную клавиатуру сохранены.

## Привязки стрелок

Ранее конец обычной стрелки хранил координату и при отрисовке пытался распознать совпадающий пост по почти точному равенству. Это ненадёжно при дробных координатах, округлении и включённом ограничении горизонтали/вертикали.

Теперь при включённом магните сохраняется постоянная ссылка на ID элемента и номер поста. Экранный значок, наконечник, ручка и зона касания используют одну раскладку постов. Ссылка восстанавливает положение при масштабе, сдвиге, перемещении объекта, сохранении и повторном открытии. При наведении на явный пост привязка имеет приоритет над свободным ограничением линии; свободные концы по-прежнему подчиняются модификаторам.

Ссылки `labAnchors` являются дополнительными полями существующих `dm` / `drw`; стандартные координаты миллиметров остаются в контракте v81. Номер поста отражается вместе с геометрией при выгрузке и восстановлении стены другой стороны. Явно отвязанные стрелки и стрелки с выключенным магнитом получают маркер намерения, который сохраняется при JSON-обмене, чтобы не привязывать их заново после восстановления.

Для старых стрелок без сведений о посте используется только однозначное близкое совпадение. Далёкие или неоднозначные концы не переназначаются автоматически. Если старая стрелка изначально была нарисована мимо поста, её конец нужно один раз подтянуть к нужному посту при включённом магните; далее сохраняется постоянная ссылка. Данные старого замера не удаляются.

## Установка и проверка

Отдельный пакет `ge.akrix.measure.lab`, versionCode4, versionName`0.4-v81-lab`. Прежняя подпись и те же origins: обновлять поверх Measure Lab без удаления. Исходная v81 в выборе версий и рабочее приложение Measure не изменяются.

Независимые сценарии — `docs/qa-v04.md`, `tests/qa-v04-anchors.cjs`, `tests/qa-v04-placement.cjs`. Проверяются настоящие события пера и касания, дробные координаты тройного блока, включённый модификатор 0/90°, масштаб в обе стороны и перемещение вида. Не считать один лишь факт неизменности модельных координат доказательством правильной экранной привязки.

При упаковке проверяются подпись, версия и побайтовое совпадение файлов внутри APK с проверенными исходниками. Физический Android/GLM/камера в этой среде не проверяются; их нативный код не менялся, кроме номера версии.
