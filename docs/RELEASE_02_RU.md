# Measure Lab 0.2 — исправление стрелок по проверке на телефоне

Пакет `ge.akrix.measure.lab`, versionCode 2, versionName `0.2-v81-lab`. Используется прежняя подпись. Обновление устанавливается поверх Measure Lab 0.1; origins и базы данных не переименованы. Исходная v81 в переключателе и установленное рабочее Measure не изменялись.

## Исправления

- Удалён отдельный модальный редактор «Размер стрелки». Создание обычной стрелки, размерной линии и привязанной стрелки RZ не открывает ввод или клавиатуру. Сначала можно нанести разметку, потом выполнить замер.
- Явное нажатие на поле обычной стрелки или размерной линии открывает родной встроенный `#w3f` и клавиатуру v81. Отдельные DOM-окна не создаются. CSS активного поля взят из v81: исходные размер, жёлтая рамка и подсветка. Настройки размеров пассивных подписей на холсте остаются доступными.
- Возвращены родные v81 рисование линий/наконечников, масштабирование и поведение RZ. При значении размера наконечника 9 применяется точная исходная формула v81, другие значения настройки пропорционально меняют её результат.
- Устранено расхождение физических координат постов и экранных значков розеток. v81 раздвигает посты на экране при уменьшении для читаемости; линии, наконечники и зоны касания теперь используют одинаковые видимые центры, сохраняя реальные миллиметры в модели и экспорте.
- Синие точки привязки авторазмеров рассчитываются из тех же экранных концов, что и линия; старая точка не дорисовывается отдельно.
- Привязка обычных стрелок добавлена к центрам и постам розеток, центрам/углам других объектов, опорным точкам стен и разметки. Ручки концов также используют привязку. У обычной стрелки есть штатная кнопка магнита.
- Устранены два конфликта: общий переключатель привязки больше не блокирует включённый магнит инструмента; повторная привязка уже найденного крайнего поста больше не перескакивает на средний пост.
- Привязка сохраняет стандартные координаты в миллиметрах. Механизм RZ остаётся средством связи размера с перемещаемой коммуникацией. Новый формат ID или новый формат экспорта не вводился.

## Проверка

Независимый QA воспроизвёл проблему на сохранённой версии 0.1 настоящими жестами и записью операций Canvas. Измерялись экранные наконечники, видимые центры розеток, зоны касания и положение полей; проверка не ограничивалась неизменностью координат модели.

Сценарии: несколько отдельных розеток и тройной блок; масштаб 0.1 / 0.2 / 0.35 / 0.5 / 1 / 2 с перемещением; настоящая постановка стрелки; отсутствие автоматического ввода; нажатие поля и родная клавиатура; фактическая привязка к крайним постам; выключенный магнит; сохранение числового значения; исходная формула наконечника. Отдельно проверены автоматические синие точки привязки.

Сохранение/экспорт (14), интерфейс/изоляция (9), боковые стены (5) прошли регрессионные сценарии. Подробные результаты исправлений стрелок — `docs/qa-v02.md`, сырые проверки — `tests/qa-arrows-v02-current.json` и `tests/qa-arrows-v02-auto-handles.json`.

Компиляция, Android manifest, подпись и побайтовое совпадение встроенных файлов с проверенными исходниками проверяются при финальной упаковке. Физические GLM/камера и полный UI конструктора в этом обновлении не тестировались; их код не менялся.
