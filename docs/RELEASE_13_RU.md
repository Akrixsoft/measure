# Measure 82.13 (Lab 0.13)

Выпускается как преемник v81: пакет `ge.akrix.measure`, версия 82.13, код 82013 (см. «Установка» ниже). Исходная v81 не изменена (SHA-256 сверяется сборкой). Перенос обмера из 0.12 — через JSON.

## План — колонны
- Колонну можно тянуть целиком пером (или пальцем без пера). Касание без сдвига — выбор.
- С магнитом грань колонны ложится на ближайшую параллельную стену, у прямого угла — две грани. Во время протяжки зона привязки подсвечивается: стена — голубой линией, угол — точкой.
- Растягивание за угловой маркер тоже притягивает угол к линии стены / к углу.
- Второй палец или отмена касания во время протяжки — откат без лишнего шага ↶. Одна протяжка — один шаг ↶.

## Развёртка стены — размеры до колонн и ниш плана
- Поля отступов слева/справа, ширины и глубины колонн, уступов у краёв стены (в т.ч. авто-выступов общих стен, фасонного контура) и ниш плана больше не «справочные»: ввод меняет план. Ширина — край у стены на месте (у правого края стены — правый), глубина — от грани стены. Шаг ↶ ↷ на развёртке.
- Высота колонны плана — во всю высоту помещения, ввод не предусмотрен (сообщение).

## Объекты стены
- При активном инструменте касание другого объекта выбирает его (и его можно тянуть), касание пустого места — снимает выделение, следующее — ставит новый.
- Посты розетки/выключателя: выбранное число (1–5) запоминается и ставится следующим объектам того же вида.
- Удаление / ↶ / ↷ — общие кнопки для объектов, зон, щитов и трасс (проверено).

## Установка — Measure 82.13 (преемник v81)
Сборка выпускается как основное приложение: пакет `ge.akrix.measure`, ключ подписи v81 (сертификат 4f15e141…), versionCode 82013, имя «Measure», оригинальный логотип, без экрана выбора версий. Ставится обновлением поверх v81 (versionCode 101). **До установки** выгрузите нужные обмеры v81 в JSON: данные v81 жили в веб-хранилище akrixsoft.github.io, в 82.13 они не видны, а открыть v81 после обновления нельзя. Перенос — импорт JSON. «Назад» сохраняет замер и закрывает приложение.
