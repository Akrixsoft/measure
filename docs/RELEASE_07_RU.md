# Measure Lab 0.7 — фото и инструменты коммуникаций

Пол выбранной стены дополнительно обрезается по внешней границе основной грани. Его заливка и контур не должны перекрывать фотографию стены. Защита касается только условной площадки пола; разметка и намеренно нанесённые объекты сохраняются.

В режиме размеров коммуникаций нижняя строка содержит выбор, единый инструмент с перекрестьем стрелок и лупу. Ось стрелки выбирается по большей протяжке жеста; отдельная кнопка «по высоте» объединена с обычной стрелкой. Затем идёт горизонтально прокручиваемая палитра, справа — прежние отмена, повтор и удаление. Цвет применяется к выбранной стрелке и запоминается для новых; сохраняется при открытии замера и JSON-переносе.

Во второй строке снизу доступны все видимые виды коммуникаций родного набора. Ряд прокручивается по горизонтали. Для перестановки удерживать значок около 0,4 секунды и перетащить; быстрый свайп прокручивает ряд. Порядок сохраняется на устройстве. Возможность выбрать пост многопостовой розетки сохранена.

Новая компоновка включается только в режиме размеров коммуникаций. Объекты по-прежнему ставятся без автоматических стрелок: поставить → переместить выделенное → снять выделение касанием в стороне → поставить следующий. Создание стрелки автоматически не открывает ввод; используется родная клавиатура v81.

Отдельный пакет `ge.akrix.measure.lab`, versionCode 7, versionName `0.7-v81-lab`. Устанавливать поверх Measure Lab без удаления. Исходная v81 неизменна.
