# Measure 82.18

Пакет `ge.akrix.measure`, код 82018, ключ v81. Ставится обновлением поверх 82.17; данные 82.17 переносятся автоматически (старая база не удаляется — откат на 82.17 возможен). Ориентация — всегда книжная.

## Главное
- **Стартовое окно — проекты:** строка «клиент · проект», дата справа; ⋮ на строке и долгое нажатие — меню снизу; папки, перемещение, архив, корзина с «Вернуть»; «Удалить навсегда» — только из корзины. Поиск, сортировка.
- **Единый холст проекта («Скетч»)** не закрывается: ✓ — сохранить и выйти в список. Фото, стены, план, заметки — на одном холсте; любые инструменты (размеры, стрелки, текст, рисование) работают на всём холсте, включая фото; футляр — на подложке, стене и плане.
- **Холст ничего не перестраивает сам:** ни ✓, ни открытие, ни импорт, ни миграция не двигают объекты. Меняется только вид.
- **Фото:** по одному и группой из галереи — столбцом ниже последнего объекта; выделение одного/группы и перенос (разметка едет вместе); масштаб за углы и двумя пальцами; прямоугольная подрезка (исходник цел). Разметка принадлежит фото, на котором её поставили.
- **Стена по фото:** 4 угла → ▣ Стена; фото масштабируется от центра рамки так, что рамка = L×H стены (фото получает реальный масштаб); область стены — в свободное место.
- **Удаление — только 🗑.** ↶/↷ возвращают любые шаги всех поверхностей, включая фото с изображением, и после перезапуска; изображение удаляется физически только «Удалить навсегда».
- **Авторазмеры стены — до граней элементов:** ригель 381 у потолка → «2 319 + 381». Поле высоты ригеля меняет ригель, высота стены — только своим полем.
- **Объекты:** поля и ручки — при любом инструменте; при активном инструменте касание ставит объект (как v81); поле Z (глубина: выступ +, ниша −).
- **План:** введённая длина стены перестраивает план; «Новое помещение» — имя и высота H; H помещения видна на плане без «⋯»; помещение выбирается в шапке проекта.
- **Зоны (комнаты) и конструкции:** зона — виртуальная комната внутри помещения; конструкция — тип (Кухня, Шкаф, Гардероб, Прихожая, ТВ-зона, Стеллаж, Санузел, Другое) + комната + целые стены; одна стена — в нескольких конструкциях.
- **∠°** — наклон всего вида, как v81; значение = угол на экране (180 = 180°).
- **«Назад» Android:** клавиатура → отмена действия → снятие выделения; выход — вторым нажатием за 2 с.
- **Автообновление:** веб-часть обновляется сама (проверка SHA-256 и подписи ключом APK, откат при сбое), APK — через установщик Android. Публикация — только по тегу выпуска.

## Выгрузка для конструктора (akrix-zamer v3, только новые необязательные поля)
`els[].d` (глубина колонны/ригеля/короба/ниши, мм), `no` (номер объекта по проекту), `labRooms[].zn` (номер комнаты), `o.prd[] = {id, no, type, name, room, walls:[wid]}`. Выгрузка одинакова из любого режима. Импорт своей выгрузки — «Обновить» (те же id, история ↶ начинается заново) или «Новым проектом». Пример: AI-team `tasks/reports/AKX-2026-0013/exports/z7-example-82.18.json`.
