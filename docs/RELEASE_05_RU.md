# Measure Lab 0.5 — направление стрелок и полей

При включённом модификаторе 0/90° стрелка и размер соблюдают направление по осям стены, в том числе при привязке к посту коммуникации. Модификатор параллельности сохраняет штатный порядок v81: сначала параллельность выбранному образцу, затем ограничение 0/90°, если включены оба.

Если линия начинается в свободном месте и заканчивается у поста, свободное начало выравнивается по направлению через этот пост. Если начало уже привязано, несовместимая привязка второго конца не отменяет ограничение направления.

Поле значения расположено в середине видимой линии и повёрнуто вдоль неё. Текст остаётся читаемым при обратном направлении стрелки. Правило действует для обычных стрелок, размеров и сохранённых ручных размеров коммуникаций. Область касания учитывает поворот. Активное поле ввода также поворачивается; используется прежний ввод v81 и его клавиатура. При создании стрелки ввод автоматически не открывается.

Сохраняется порядок расстановки 0.4: поставить → переместить выделенное → касанием в стороне снять выделение → поставить следующий объект. Автоматические стрелки элементов отключены. Исходная v81 не меняется.
