# Measure Lab — исправление выгрузки

## Подтверждённая причина

В исходной v81:

- `cvBase81()` возвращает `S.room` либо `S.room0`. У отдельной плоскости, созданной кнопкой «＋ Плоскость», оба отсутствуют. Новая панель `zExp` считает холст пустым; `cvOut81()` формирует объект с пустым `rooms`.
- Старый `exportJson()` немедленно возвращается при отсутствии `S.sol`, хотя ручная стена с `S.q4.blank`, L и H является полноценным замером без решения по маркерам.
- Вызовы асинхронной выгрузки из onclick не имеют верхнего обработчика отказов: исключение выглядит как отсутствие реакции.

Неподтверждённая первоначальная гипотеза владельца (имя/ID помещения) не выдана за причину. Незамкнутое помещение с явным `name=''` уже корректно экспортировалось в независимом baseline-тесте QA. В исходнике `plN = pts.length - (closed ? 0 : 1)` поддерживает открытые полилинии.

## Что изменено

`web/lab-export.js` загружается после inline-кода v81 только в экспериментальной версии:

- Экспорт отдельной плоскости повторно использует действующий `exportRoomObj`, `wlInf`, `rfOut`, `geoOut` и реальный контракт `akrix-zamer / kind:object / v:3`.
- Одна отдельная стена представлена открытым экспортным участком с двумя точками, одним `wl[0]`, `geo.walls[0]` и необязательным `name`: стандартная «Плоскость» передаётся как `name:''`, пользовательское название сохраняется. Имя помещения не запрашивается. Такой участок существует только при выгрузке: в базу не добавляется искусственное помещение.
- room ID, wall ID и object ID детерминированы исходным постоянным ID плоскости, не зависят от её имени, даты или размеров; повторная выгрузка и перезагрузка сохраняют привязки.
- Сначала сохраняется текущая плоскость, затем обновляется snapshot `out` с явным пробросом ошибок. Сохраняются существующие элементы, точки, фотографии, размеры, стрелки и рисунки в штатном пути преобразования.
- Учитывается сторона взгляда (`wsd:-1`): X отдельной плоскости остаётся от её собственного левого края, не зеркалится случайно.
- Нет выдуманных размеров: плоскости без L и H предлагается их ввести. Приблизительные значения сохраняют штатные `apx` признаки.
- Незамкнутые помещения не получают предупреждение «контур не замкнут» и не замыкаются автоматически. Другие предупреждения и признак приблизительных длин остаются.
- Экспортные действия перехватывают ошибки и показывают явное сообщение вместо молчания кнопки.

Дополнительные поля короткой стрелки реализует геометрический агент. Импорт рисунков не заменён: исходный `impWall81` сохраняет дополнительные поля `drw` через spread; восстановление `v → vm` реализует геометрический агент. Небольшая обёртка `zImpExp` сохраняет пустое имя после штатного импорта, который иначе подставлял «Помещение» в данные.

## Потребитель: фактические источники

Репозиторий `Akrixsoft/akrix-soft`, commit `320c2f9a04c981f390b24c204f1de66cf13714c8`:

- `calc/build/p879.py`: `msImpObj` принимает `kind:room`, `ms.pts.length >= 2`; `name` может быть пустым. Построение содержит самостоятельный путь для `m.closed=false`.
- `calc/build/p894.py`: актуализированный `zwSet` принимает комнаты с двумя точками, сохраняет `name:''`, room ID и `oid`; стена определяется по `ms.wid / wl[k].id / geo.walls[].id`.
- `calc/PLAN_0311_zamer_akrix.md`: описание текущего контракта миллиметров, ID, координат и дополнительных полей. Новый самодельный формат превью не используется.

Точная функция `zwSet` вынесена в `tests/constructor-zwSet-v894.js` как тестовый источник, с фиксацией commit. `tests/export-consumer.cjs` прогоняет реальную выгрузку через эту функцию и проверяет сохранение имён, ID, открытости, физических длин и геометрии.

## Границы проверки

Полный `Akrix/akrix-furniture.html` (~9,2 MB) не удалось получить через доступный GitHub коннектор: превышен размер/transport closed, чтение диапазонов возвращает пустой текст. Поэтому исполнение полной UI-сборки мебели в конструкторе пока не заявляется как пройденное. Исполнение реальной функции импорта потребителя и roundtrip в самом Measure проверяются отдельно от этого ограничения.

Нативный канал сохранения Android не возвращает JavaScript подтверждение завершения. Оболочка должна показывать результат/ошибку сохранения; файлы и импорт на физическом телефоне требуют проверки владельцем тестового APK. Исходная v81 не редактировалась.
