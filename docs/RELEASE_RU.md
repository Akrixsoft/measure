# Measure Lab 0.1 — тестовый APK

Дата: 08.11.2026. APK 0.1 (архив): `artifacts/measure-lab-v0.1.apk` (963500 байт).

SHA256: `345a9618bc4f4c5827a0595b38bdca3b8f321d65ca56e4cfd33f3ab10d8751ae`.
Пакет: `ge.akrix.measure.lab`. Android 8 и новее. Это отдельная установка рядом с обычным Measure.

## Две версии внутри

При входе выбирается исходная v81 либо изменённая v81 Lab. Обе версии полностью встроены в APK; интернет для запуска не нужен. Данные и настройки разделены по двум origins WebView. Установленная рабочая версия, её сайт и данные не изменялись.

Кнопка «Версии» возвращает к выбору после завершения записи в IndexedDB. При ошибке записи переход не выполняется. Незавершённый ввод в новом диалоге также препятствует переключению.

## Изменения Lab

- Открытые помещения и группы нужных стен с независимыми названиями, без требования замыкать контур.
- Одинаковые квадратные кнопки стен с горизонтальной прокруткой.
- Полоса инструментов во всю ширину; модификаторы справа над ней.
- Управление сохранением активного инструмента для повторного применения.
- Размерные линии без поперечных засечек; экранный размер наконечников; короткие размерные стрелки коммуникаций, направленные к месту отсчёта; числовые поля обычных стрелок.
- Схематичные сохранённые элементы соседних стен без размеров, с проекцией на боковые грани. Используется существующая глубина боковой грани v81; элементы за её пределами не сжимаются искусственно.
- Настройки с живым примером и сохранением: текст от 6 px, поля от 10 px, линии, наконечники, точки, сетка и привязки. Для читаемости высота поля не меньше высоты выбранного текста + 2 px.
- Исправлена рабочая выгрузка отдельной ручной плоскости без имени помещения в штатный контракт конструктора Akrix v3; ошибки выгрузки больше не скрыты. Стабильные ID, размеры, точки и элементы сохраняются.
- Android-оболочка принимает JSON для восстановления, сохраняет нативные мосты дальномера/камеры/файлов и безопасную передачу файлов.

## Команда

Задачи распределены между пятью агентами доступной среды Codex: Android, интерфейс, геометрия, экспорт и независимый QA. Главный агент интегрировал результат, проверил безопасность оболочки, подпись, manifest и точное совпадение встроенных исходников с проверенными файлами. Внешние Gemini/Claude/API не запускались.

## Проверки и границы

- Исходная v81 побайтно сохранена: SHA256 `b6c6987e16e63adf77b0e46a762805393b3e108955822001aed579f0c988d191`.
- Компиляция Android и lintVitalRelease прошли; APK Signature Scheme v2 проверена независимо повторным apksigner.
- Manifest проверен через aapt2: отдельный пакет, minSdk26, targetSdk34.
- HTML и все расширения внутри APK побайтно сверены с актуальными исходниками.
- 50 независимых браузерных проверок прошли; сценарии описаны в `docs/qa.md`, сырые результаты — `tests/qa-integrated-result.json`.
- Реальная функция импорта `zwSet` из исходников конструктора приняла три фактические выгрузки: отдельную плоскость, открытое помещение и помещение с элементами/размерами/стрелкой.
- Полное UI-построение мебели в конструкторе пока не проверено: файл конструктора превышает доступный лимит GitHub-коннектора. Это не заменено выдуманным утверждением о полной совместимости.
- Физическое Android-устройство, Bluetooth GLM, камера и системное меню передачи требуют тестирования на телефоне. Сценарии — в `docs/TESTING_RU.md`.

Это первая тестовая сборка, предназначенная для практической проверки и дальнейших правок. Общая диагностика не означает, что уже проверены все возможные комбинации инструментов и аппаратных устройств.
